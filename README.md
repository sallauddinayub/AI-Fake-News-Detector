# 🤖 AI Fake News Detector

A hybrid AI system using DistilBERT + rule-based logic to detect fake news with a modern UI.

---

## 🚀 Features
- Deep Learning (DistilBERT)
- Rule-based correction system
- Real-time Flask API
- Glassmorphism UI with animations

---

## 🧠 Tech Stack
- Python, Flask
- Transformers (HuggingFace)
- HTML, CSS, JavaScript

---

## 📂 Project Structure
backend/ → Flask API  
frontend/ → UI  
ml/ → Training scripts  

---

## ⚙️ How to Run

```bash
cd backend
python app.py
